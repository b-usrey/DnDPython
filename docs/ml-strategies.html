🤖 ML Strategies

Trained Combat Intelligence

Instead of handcrafted rules, ML strategies learn which of the five tactical behaviours (Aggressive, Kite, Retreat, Focus Fire, Protect) to use each turn by training over thousands of simulated combats. Three different learning algorithms are implemented, each with different trade-offs between sample efficiency, training time, and final performance.

Q-Table Reinforcement Learning

File format: .npy  ·  Model type: rl

A classic tabular Q-learning approach. The 12-dimensional observation vector is discretised into a finite number of state buckets, and a Q-value is stored for each (state, strategy) pair. After every episode, values are updated using TD(0).

State space3⁹ = 19,683 states
Learning rateα = 0.20
Discountγ = 0.95
Explorationε-greedy, decaying
Best for: fast experimentation. Converges quickly on simple scenarios but struggles when the state space is complex.

Evolutionary Strategy

File format: .npy  ·  Model type: evo

A population of weight matrices (W of shape 12 × 5) compete across combat episodes. Each turn, the strategy is chosen as argmax(W @ obs). After each generation, the top performers survive and mutate, gradually pushing the population toward higher win rates.

Population20 individuals
Elite fraction20% kept per generation
MutationGaussian noise std 0.1
CrossoverUniform, p = 0.5
Best for: parallelised training across many scenarios. Slower convergence than RL but more robust to reward noise.

Deep Q-Network (DQN)

File format: .pt  ·  Model type: dqn

A small PyTorch MLP (12 → 64 → 32 → 5) learns to map the raw observation vector directly to Q-values for each strategy. Experience replay and a separate target network stabilise training. Epsilon decays from 1.0 to 0.05 over the course of training.

Architecture12 → 64 → 32 → 5
Replay buffer10,000 transitions
Batch size64
Target updateEvery 100 episodes
Best for: highest ceiling performance. Requires more episodes to converge but can learn nuanced multi-step strategies the table-based methods miss.

To use a trained model in the simulator, copy the saved file into docs/models/ and select it from the Trained Model dropdown on the Simulator page.
