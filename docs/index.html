DnDPython

D&D 5e Combat Simulator & Tactical AI Engine

Demo Features How It Works Simulator Roadmap Get Involved

See It In Action

A fully simulated D&D 5e encounter — complete with initiative, movement, attacks, saving throws, and class features — running entirely in Python.

What's Inside

🗺️

Battle Map Engine

Grid-based maps with walls, difficult terrain, line-of-sight, and range calculations — faithful to the 5e ruleset.

🧠

Tactical AI

Creatures don't just swing randomly. The AI evaluates positioning, target priority, and action economy each turn.

🤖

Machine Learning Strategies

Reinforcement learning and evolutionary algorithms that train combat strategies over thousands of simulated encounters.

⚔️

Classes & Subclasses

Fighter (Champion), Ranger (Gloomstalker) with authentic class features, fighting styles, spells, and feat support.

🐉

Monster Roster

Goblins, Orcs, and growing. Each monster has accurate stat blocks, attack profiles, and weapon role assignment.

📜

JSON Scenarios

Define any encounter in a simple JSON file — parties, monsters, map layout, and starting positions.

How It Works

I

Define Your Scenario

Write a JSON file describing your party — classes, subclasses, stats, items, and feats — alongside the monster encounter and map layout.

II

Roll Initiative

The engine places creatures on the map, rolls initiative, and begins the encounter loop — one turn per creature, every round.

III

Tactical AI Takes Over

Each creature evaluates movement options, attack targets, and available actions according to its strategy — rule-based, RL, or evolutionary.

IV

Analyse the Results

Win rates, round counts, tactic distributions, and convergence graphs — run hundreds of episodes and see what actually works.
